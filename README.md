# 개인 커스텀 Spyder 테마

개인적으로 커스텀한 Spyder(`spyder6_ok97465`)에서 사용하기 위한 개인 테마 저장소입니다. 여러 에디터의 테마를 Spyder에 맞게 옮기고, 일부 배색은 개인 취향에 맞게 조정했습니다.

| 테마 | 간단한 설명 |
| --- | --- |
| [Alabaster](alabaster) | 밝은 회색 배경과 최소한의 구문 강조를 사용하는 라이트 배색 |
| [Ayu](ayu) | 차분한 Ayu 다크·라이트 배색 |
| [Brutalism](brutalism) | 브루탈리즘 건축에서 영감을 받은 배색 |
| [Carbonfox](carbonfox) | 무채색 짙은 회색 배경의 Nightfox 계열 다크 배색 |
| [Catppuccin Mocha](catppuccin-mocha) | 부드러운 파스텔 계열의 개인 변형 |
| [Dracula](dracula) | 보라색과 분홍색이 돋보이는 배색 |
| [Flexoki](flexoki) | 먹색 다크와 따뜻한 종이색 라이트 배색 |
| [GitHub Dark](github-dark) | GitHub의 Dark Default 배색 |

| [Notepad++](notepad++) | Notepad++ 기본 테마를 바탕으로 조정한 배색 |
| [Nordfox](nordfox) | VS Code Nordfox의 차가운 청회색 배경과 차분한 구문색 |
| [Obsidian](obsidian) | Eclipse Obsidian을 바탕으로 조정한 배색 |
| [One Dark Pro](one-dark-pro) | One Dark Pro의 다크 배색 |
| [PaperColor](papercolor) | 무채색 배경에 선명한 구문색을 사용하는 다크·라이트 배색 |

| [Solarized](solarized) | Solarized를 바탕으로 색상 범위를 확장한 배색 |

| [VS Code Modern](vscode-modern) | VS Code의 Dark Modern·Light Modern 배색 |

Matplotlib 플롯용 스타일은 [mplstyle](mplstyle/README.md)에 있습니다.
다크 테마 33개에 어울리는 27가지 배색을 `plt.style.use()`로 선택해 적용할 수 있습니다.
